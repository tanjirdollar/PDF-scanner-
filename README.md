# Bijoy to Unicode Converter (বিজয় থেকে ইউনিকোড কনভার্টার)

একটি শক্তিশালী বাংলা টেক্সট কনভার্সন ও রিপেয়ারিং ওয়েব অ্যাপ্লিকেশন। এটি বিজয় কীবোর্ড (SutonnyMJ ফন্ট/ANSI এনকোডিং), ভাঙা ইউনিকোড টেক্সট, PDF ডকুমেন্ট এবং স্ক্যান করা ছবি (OCR) থেকে শুদ্ধ ইউনিকোড বাংলায় রূপান্তর করে।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **বিজয় থেকে ইউনিকোড রূপান্তর**: SutonnyMJ/ANSI টেক্সটকে নিখুঁত আধুনিক ইউনিকোড বাংলায় রূপান্তর।
2. **স্মার্ট যুক্তবর্ণ ও কার-চিহ্ন মেরামত**: বিভক্ত ও-কার, ঔ-কার, পূর্বে থাকা ই-কার/এ-কার ও যুক্তাক্ষরের অনাকাঙ্ক্ষিত ফাঁকা স্থান স্বয়ংক্রিয়ভাবে মেরামত।
3. **PDF টেক্সট এক্সট্রাকশন**: ডিজিটাল ও স্ক্যান করা PDF ফাইল থেকে সরাসরি বাংলা টেক্সট নিষ্কাশন।
4. **ইমেজ OCR**: ছবি বা ডকুমেন্টের স্ক্যান করা পাতা থেকে টেক্সট এক্সট্রাকশন।
5. **Google Drive ব্যাকআপ**: গুগল ড্রাইভ থেকে সরাসরি ডকুমেন্ট ওপেন করা এবং রূপান্তরিত ফলাফল সেভ করার সুবিধা।
6. **অফলাইন সাপোর্ট**: সাধারণ কনভার্সনে কোনো ক্লাউড টোকেন বা এপিআই কি প্রয়োজন নেই; সম্পূর্ণ লোকাল অ্যালগরিদমে কাজ করে।
7. **টেক্সট-টু-স্পিচ (TTS) ও হিস্ট্রি**: বাংলা উচ্চারণে পড়ে শোনানো এবং পূর্ববর্তী রূপান্তরের লোকাল হিস্ট্রি সংরক্ষণ।

## 🛠️ লোকাল সেটআপ ও রান করার নিয়ম (Local Setup)

### ১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/your-username/bijoy-to-unicode-converter.git
cd bijoy-to-unicode-converter
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ৩. এনভায়রনমেন্ট ভ্যারিয়েবল কনফিগার করুন:
প্রজেক্টের রুটে `.env.example` ফাইলটিকে কপি করে `.env` তৈরি করুন:
```bash
cp .env.example .env
```
এরপর `.env` ফাইলে আপনার `GEMINI_API_KEY` (যদি AI ডিপ রিপেয়ার ও ইমেজ OCR ব্যবহার করতে চান) বসান:
```env
GEMINI_API_KEY="আপনার_জেমিনি_এপিআই_কি"
```
*(নোট: এপিআই কি না দিলেও সাধারণ বিজয়-টু-ইউনিকোড রূপান্তর পুরোদমে কাজ করবে)*

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে `http://localhost:3000` ওপেন করুন।

### ৫. প্রোডাকশন বিল্ড তৈরি করুন:
```bash
npm run build
```
